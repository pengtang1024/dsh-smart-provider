# 设计哲学与评审尺子

本文是设计哲学与评审尺子，不是视觉风格指南；后续任何设置页改动先用它评审，再谈实现。

> 范围：本文只回答"什么样的决定对用户是好决定"。它不规定任何视觉表现、控件形态或厂商风格，也不构成改造清单。它描述的是判断标准，不是做法。

## 一句话本质

好的设置页不是把配置摊开给人看，而是让人用最短路径做出一个自己能理解、能验证、能反悔的决定：把复杂留给自己，把确定感交给用户。

## 七条原则

每条原则含一个短名、一句可判定的定义，以及一条用于评审的违反判据。判据只描述用户能否完成、能否说清、能否反悔，不指向任何具体控件。

### 1. 目标可达性

- **定义**：用户带着一个意图进入设置流程时，存在一条不必先理解系统内部结构就能走完的路径，且终点给出"意图已落实"的可确认状态。
- **违反判据**：用户必须先知道某个内部概念（配置项 internal 名称、后端机制、对象之间的关系）才能迈出第一步；或走完之后仍需自己推断意图是否生效。

### 2. 真实可见

- **定义**：系统呈现的状态与它实际将采取的行为一致；会改变结果的前提、生效范围、覆盖关系，在决定之前就能被看见，而不是在失败之后才被解释。
- **违反判据**：界面显示"已启用 / 已保存"而实际行为未改变；或某个设置的生效条件、优先级、作用对象只在出问题后才被告知。

### 3. 可撤退

- **定义**：每个有后果的决定都留有回到决定前状态的路，且这条路的成本明显低于做出决定的成本。
- **违反判据**：一旦确认便无法撤销、无法回滚，或撤销需要用户重新构造原状态；或高风险决定与日常决定在可逆性上没有区别。

### 4. 一个词一个意思

- **定义**：同一术语在整个流程中指向同一概念，不同概念使用不同词；用户不必靠上下文猜测"这里的这个词是不是刚才那个词"。
- **违反判据**：同一个词在不同位置指代不同对象；或同一对象有多个未解释关系的别名，用户无法说清它们是否等价。

### 5. 按需展开

- **定义**：用户尚未形成某项决策需求时，不要求他理解或处理支撑该决策的细节；细节在该决策的上下文出现时才出现。
- **违反判据**：为完成一个简单意图必须先浏览或理解与该意图无关的高级内容；或所有细节默认同时呈现，用户必须自己划分主次。

### 6. 少动脑

- **定义**：把需要记忆、比对、换算和小心规避出错的部分交给系统；用户只做选择与确认，不做推算与抄写。
- **违反判据**：用户需要记住别处的值才能填当前选择；需要人工比对两组信息才能判断哪条生效；或必须靠谨慎操作才能避免破坏状态。

### 7. 人掌舵

- **定义**：用户始终知道自己可以停止、退出、改主意，系统接纳"不继续"这个决定；系统不替用户做出不可逆或超出其授权的变更。
- **违反判据**：流程中没有退出点，退出意味着丢失已做选择；系统自动改动却未告知；推荐或默认路径无法被拒绝。

## 冲突时谁让路

原则不是并列清单。同一处无法同时满足时，按下述顺序裁决；"A > B" 表示 B 让路于 A。

1. **人掌舵 / 可撤退 > 目标可达性**：一条更快但不能退出或不能撤销的路径，不算真正可达。效率不能建立在剥夺否决权之上。
2. **真实可见 > 按需展开**：可以暂时不展示细节，但不能为了让当前画面简单而隐藏会改变结果的前提。被折叠的内容一旦影响当前决定，必须先显形。
3. **可撤退 > 少动脑**：不能为了少一次确认而抹掉反悔机会。少动脑只在可逆的前提下成立。
4. **真实可见 > 一个词一个意思**：当用词统一会掩盖真实差别时，宁可多一个词也不要用一个词抹平事实差异；先如实区分，再谈术语一致。
5. **高频动作优先减步骤**：以上硬约束都满足之后，冲突向高频动作倾斜——经常做的事步骤更短；罕见的高风险事宁可多一步确认。

## 八维评审尺子（rubric）

每维按 0 / 1 / 2 打分。锚点只描述可观察的用户处境：用户能否走到终点、说清状态、预判后果、无损反悔、拒绝默认。评分前先写下观察证据，再写分数；分数用于比较同一维度的前后状态，不跨维相加求总分。

### D1 目标可达性

- **0**：常见意图走不到"已完成"的确认状态，或必须借助文档、源码、他人才能走完。
- **1**：意图可以达到，但需绕路或反复进入多个区域；完成后需要用户自己推断是否生效。
- **2**：常见意图各有一条最短路径，终点给出明确的完成信号，用户无需了解内部实现即可判断意图已达成。

### D2 状态透明度

- **0**：展示状态与实际行为不符，或关键前提（是否生效、何时生效、作用于谁、被谁覆盖）完全不可见。
- **1**：状态大体可见，但生效条件、覆盖范围或优先级需要用户自己推理；反馈出现在结果已不确定之后。
- **2**：决定之前能看见前提、当前值与预计后果；决定之后能直接看到实际发生了什么、是否与预期一致。

### D3 决策可逆性

- **0**：决定不可撤销，或撤销需重建原状态；高风险与日常操作在可逆性上没有区分。
- **1**：可撤销，但路径不明确、步骤多于做出决定本身，或撤销后状态无法确认。
- **2**：每个有后果的决定都有对应的回退路径，回退成本明显低于做出决定，用户能在决定前预知如何反悔。

### D4 术语与心智模型

- **0**：同一词在不同位置指代不同对象，或同一对象有多个未解释的别名，用户只能靠猜。
- **1**：术语大体一致，但个别概念需靠上下文或文档才能区分；用户能完成任务却说不清自己改了什么。
- **2**：每个术语只有一个含义，概念关系自洽；用户能用系统自己的语言准确复述"我做了什么、它影响什么"。

### D5 信息密度与节奏

- **0**：所有细节同时压在用户面前，用户必须自己划分主次；或为一个简单意图被迫穿过大量无关内容。
- **1**：有主次但边界不稳——与当前决定无关的细节仍在争夺注意力，或必要细节藏得过深。
- **2**：每一步只面对与当前决定相关的信息；需要时细节可及，不需要时不占位；从意图到决定不用来回跳转。

### D6 一致性

- **0**：同类情形在流程位置、顺序、说法或后果上各不相同，用户无法把别处学到的经验迁移过来。
- **1**：大体一致，存在少量未说明原因的例外，用户偶尔需要重新学习。
- **2**：同类情形遵循同一套规则，例外可解释且可预期；一处形成的判断在别处同样成立。

### D7 容错性

- **0**：一次误操作立即造成损失且无提示；输入错误或前提不满足时，用户只能从失败现象反推原因。
- **1**：有错误提示，但只说"出错了"而未给出可执行的下一步；或阻止了错误却不说明被阻止的原因。
- **2**：错误在造成后果前被拦下，说明原因并给出可执行的下一步；误操作后能无损回到正常路径。

### D8 用户掌控与退出自由

- **0**：流程没有退出点，退出意味着丢失已做选择；系统可替用户完成有后果的变更而不告知。
- **1**：可以退出，但退出路径不清晰、代价未说明；默认路径难以拒绝，用户不确定自己是否还能改主意。
- **2**：任何时刻都能停、退、改主意且代价事先说清；系统不替用户做超出授权的不可逆决定，推荐与默认都可被拒绝。

## 当前三 Tab 的观察结论

对当前「总览 / 路由设置 / 花费与健康」三个 Tab 按上述尺子做只读观察，结论如下。

- **最低两维是 D4 术语与心智模型 与 D8 用户掌控与退出自由。** 共同表现是：用户能看见不少信息，但要用自己的话复述"这个值指什么、它与另一个值是什么关系"仍然费力；而"不继续、改主意、退出"在流程中不是一个被明确尊重的动作。这不是单点措辞问题，而是术语系统与退出契约尚未成为设计的一等公民。
- **次级观察是 D6 一致性 与 D5 信息密度与节奏。** 同类情形在不同位置的说法与展开程度不完全对齐；用户有时会为与当前决定无关的细节付出注意力。二者低于 D1 / D2 / D3 / D7，但尚未形成阻断性障碍。
- **其余维度未出现同等级的系统性塌陷。** 这不等于满分，只表示在本次观察中它们不是主要短板。

本节是观察结论，不是改造任务清单：它只记录"按这把尺子看，现在处在什么位置"，不规定下一步改什么、改在哪里、怎么改。任何改动仍需先用本文评审，再谈实现。
